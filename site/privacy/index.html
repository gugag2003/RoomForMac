Privacy

RoomForMac does its work on your Mac. This page says what leaves it, and what this website sees. It describes the current version of the app.

In short

  • RoomForMac has no accounts, no ads and no trackers.
  • About once a day the app asks GitHub for a small file to find out whether a new version exists. GitHub sees your IP address and the app’s name and version.
  • This website is hosted by GitHub Pages, which logs the IP addresses of visitors.
  • Nothing else leaves your Mac. When a later version sends anything more, this page changes first and says what, to whom and why.

Update checks

RoomForMac looks for a new version about once a day, and whenever you choose Check for Updates. Each check downloads one file from GitHub: @RFM_FEED_URL@. GitHub sees your IP address and the app’s name and version, as it does for any download. RoomForMac does not send a system profile, which would be a list of your hardware and software.

If there is a new version, GitHub serves that download too. You can turn the daily check off in Settings → General → Updates.

This website

This site is hosted by GitHub Pages. GitHub logs the IP addresses of the people who visit, for security purposes, and its own privacy statement explains how it handles them. The download button links to GitHub as well.

The site sets no cookies, has no forms, loads no scripts, fonts or images from other sites and uses no analytics. The download page asks this site for one small file, latest.json, to show the current version and checksum.

The page at /thanks/ reads a reference from its own address and builds a link that opens RoomForMac. That happens in your browser: the reference is not sent anywhere, not stored and never shown.

On your Mac

RoomForMac keeps its settings, and a log of what its cleaning engine did, on your Mac. The log is in ~/Library/Logs/RoomForMac. RoomForMac does not upload either.

The setup screen has a switch for anonymous usage data. In this version it only records your choice on your Mac: no usage data is sent.
